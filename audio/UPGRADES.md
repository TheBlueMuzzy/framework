# Audio — upgrade notes

Hand steps a game does when it updates this module, newest first. `install-module.mjs` prints the ones between the game's version and the new one.
Format: `- <version>: <step>` (LOOK CHANGE = sizes or looks change: re-take the game's screenshots and show Muzzy before re-recording them) · `Needs Dev Kit: <version>` = the install is refused on an older Dev Kit.

- 0.5.0: only for a game that already ran `audio:check -- --fix` with audio 0.4.x: that run changed how loud its tuned sounds are in the game (0.4.x didn't move volumeDb). To get the approved mix back: copy every file in `audio-originals/` back over its twin in `public/audio/`, delete `audio-originals/`, then run `npm run audio:check -- --fix` again (it now moves each change into volumeDb) and commit content/audio.json with the files.
- 0.4.0: check:framework (audio) and check:fast go red on the new promise "every sound is as loud as the others and starts on time" until the files are evened: run `npm run audio:check -- --fix` (it keeps each original in `audio-originals/`, outside public/). From audio 0.5.0 a sound that sets its own `volumeDb` (tuned by ear) keeps how loud it sounds in the game — the file's change moves into its volumeDb, and --fix prints each one it moved (Glyphtender: 16 moved, each sound within 0.05 dB of before). Commit content/audio.json with the files. A sound with several variants comes out with its variants even with each other — listen to those.
