# Game Framework

Muzzy's library of reusable game modules. Games **copy** a module in (with a version stamp), so a framework change never breaks a finished game; improvements found in a game get copied back here.

## Modules
| Module | What it gives a game | Status |
|---|---|---|
| `ui-kit/` | Standard menus, settings, dialogs, HUD — one structure, 5 styles (Clean, Cozy, Cartoon, Pixel, Neon). Install: `ui-kit/scripts/install-kit.mjs` | ✅ released (v0.1), kit 0.7.0 (0.7.0: short screens — a card in a screen's centre never lets a button hang out (it scrolls inside), takes the whole height on a short screen; Pause / Lobby side by side on a phone on its side; Settings ◀ tab ▶ when short; the first screen over the game layer dims it; tall cards grow to 52rem on desktops — Glyphtender F67; 0.6.1: carrier.travel + travellingLook — AI moves look like a person's drag; 0.6.0: target feedback — kit/drag/target.ts ghost preview, insertion marker, make room, tether, magnetic snap; HandView `insertAt` / `makeRoomAt`; 0.5.0: carry styles — kit/drag/ presets A–D + carrier, HandView `origin`; 0.4.2: control sounds — `setControlSound`, Button `sound`; 0.4.1: standard Settings Audio tab: master · music · ambience · effects · menus & buttons · mute all · mute in background · mono) (0.4.0: + IdleWarning: online "still there?" bar + "a bot is playing for you — tap to play"; HandView: a hand drawn as a rack of places; Lobby bot rows; Keyboard: ↑ ↓ jump between controls, ← → work them, no stray text caret; `<Screen scroll>`: the whole screen scrolls, no scroll bar) |
| `devkit/` | The in-game Dev Kit (` panel): colour tool + colour-blind preview, tuning sliders for `content/tuning/` (live in the game), Snapshots (save/restore a moment), Bug capture (record · mark · send to /bug), Screens (dev-only previews of gated screens in a sandbox), game tabs from the kit (AI, Sound, Review list: mark items Open / Yes / No, Text: every string in content/text/en.json), Save to `content/`, release-build switch + check. Web (React + Vite). Install: `devkit/scripts/install-devkit.mjs` | building (v0.2), kit 0.13.0 (+ search, sections, plain labels, review list, Text tab) |
| `rooms/` | Online rooms (PartyServer + wrangler on Muzzy's own Cloudflare — the only host since PartyKit's hosted platform shut down on 23 Oct 2026): short room codes, create/join, seats + host, rejoin by player id, host migration, idle players → warning → bot (a tap takes it back), kick, rematch; a server base the game's rules plug into, sending each player only their own view. Harvested from Roll Better. Web (React + Vite). Install: `rooms/scripts/install-rooms.mjs` | building (first game: Glyphtender), kit 0.6.0 (installer makes party/worker.ts + wrangler.json; + per-seat events: sendEventPerSeat; bot profiles — the host picks which bot; idle clock: warning → bot mid-turn → a tap takes it back) |
| `table/` | The foundation a turn-based game's rules stand on: one rules contract (setup · legalActions · check · apply → state + events · isOver · toAct · viewFor), events tagged with who may see them, move record + replay, fast mode, a self-test any game runs. Pure TS. Install: `table/scripts/install-table.mjs` | building (v0.4, first game: Glyphtender v0.6), kit 0.1.0 (Game core) |
| `audio/` | Sound by naming moments: the game says `playSound('seed.land')`, `content/audio.json` says what it sounds like (files, volume, pitch, variation, volume group, limits). Pure planner (variants never the same twice, random pitch/volume, copies + cooldown + priority, the pitch ladder, stale/catch-up drops) + Web Audio engine (unlock on first tap, buses → limiter, iPhone silent switch, hidden/call = drop never queue, mono, snapshots, ducking), play/drop log (`window.__audioLog`), Settings bridge. No libraries. Web (React + Vite). Install: `audio/scripts/install-audio.mjs` | building (v0.6, first game: Glyphtender beta), kit 0.1.0 (engine + rules) |

Design notes: `.planning/design/`. Plan: `.planning/ROADMAP.md`.
