Notes:
- F06 task 4 (rule checker in the kit): the rules now live in `kit/check-ui.mjs`, so every game gets them with the kit: `node src/ui/kit/check-ui.mjs src/ui` (with no folders it checks the kit itself). `scripts/check-ui.mjs` is a 12-line wrapper (same `npm run check-ui`, default kit + gallery; re-exports `checkSource` for the tests), no duplicate logic. It imports `./style/tokens.ts` next to itself, so the Node type-stripping import works wherever the kit is copied. Point it at UI folders, not all of `src/`: a 3D game's materials and shaders are full of raw colours on purpose. New test: the same exemptions work on `src/ui/kit/…` paths.
- F06 task 3 (`scripts/install-kit.mjs <game> [preset] [--dry-run]`, also `npm run install-kit -- <game>`): plain Node, no packages. Copies `kit/` → `<game>/src/ui/kit/` byte for byte (fonts too) and writes `src/ui/kit/VERSION` = the kit's version (new `kit/VERSION`, starts at 0.1.0) + the framework commit ("+ uncommitted changes" if kit/ was edited but not committed). **The kit's tests are not copied** (decision): they need jsdom + Testing Library, which games may not have, and the game's `npm test` would pick them up; the kit is tested here. Creates `content/ui/style.json` (`{ preset, tweaks: {} }`) and `content/ui/settings.json` (copy of settings.default.json) only if missing — never overwrites. Merges the kit's font credits into `content/credits.json` (paths become `src/ui/kit/fonts/…`; skips any already listed; drops kit font entries whose file the kit no longer ships; a broken credits.json is left alone with a warning). On an update it lists changed / added / removed kit files first, and deletes removed ones (games never edit the kit — edits go to the framework). Ends with next steps in plain English (start-up code, screen stack, check-ui, look at it), plus an ESLint hint when needed. 4 tests on a temp folder: fresh install, re-install keeps style/settings edits + lists changes, credits merge has no duplicates and keeps the game's own, dry run changes nothing.
- Dry run on a scratch copy of Roll Better (task 3): installed cleanly (48 files). Friction found and fixed: (1) Roll Better's TypeScript (5.9) doesn't know `focus({ focusVisible })` → ScreenStack now casts it (`as FocusOptions`); after that `tsc -b` passes with the kit in, and importing it + the 2 JSON files in main.tsx builds (fonts bundled). (2) Vite's default ESLint config flags 33 kit lines (`react-refresh/only-export-components` for the shared word lists, `react-hooks/refs` in ScreenStack) — the installer now says to add `src/ui/kit` to the game's ESLint ignores. (3) `check-ui src/` on Roll Better finds 542 problems (3D colours, the old hand-styled UI), so games check UI folders only (`src/ui`).
- F06 task 5 (`scripts/pick-sheet.mjs [screen]`, also `npm run pick-sheet -- menu`): starts its own Vite on 5180 (never 5181), shoots the gallery screen in all 5 styles at phone size (390×844, the gallery's own top bar hidden) with Playwright's Chromium, then puts the 5 shots side by side with each style's name and feel on one plain HTML page and screenshots that once → `screenshots/pick-sheet.png` (≈2100×960). No image library. ~5 s. **Default screen: settings** — compared with the main menu: the menu shows buttons and a title only, Settings shows ◀ option ▶, sliders, switches, a panel and buttons, so the styles differ more. Looked at both sheets: all 5 styles clean, no clipping.
