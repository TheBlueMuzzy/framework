- F110 (helper, 2026-10-23) calls: the manifest is per row — `{ "rows": [{ "id", "readBy": [regex sources], "hint" }] }` — so one module can have rows wired different ways; the module's name = its folder in the game (src/<name>/), not a field in the file.
