Notes:
- Muzzy 2026-10-20: link codes last 7 days. How long a match is kept depends on the game ("async Scrabble-with-friends → 30, a live game I forget during chores → 7") → a per-game setting `keepMatchDays` (any number), asked at install time and changeable later.
- Plan-lint: only the old F61 / F59 / F60 line (Goops' session). No open P0/P1 bugs.
- F96 — the live host's FREE limits, checked 2026-10-20 (developers.cloudflare.com: durable-objects/platform/pricing, durable-objects/platform/limits, workers/platform/limits): Workers 100,000 requests/day, 10 ms CPU per request, 100 workers per account · Durable Objects 100,000 requests/day (alarm runs count as requests), 13,000 GB-s/day, SQLite 5 million rows read/day, **100,000 rows written/day** (each `setAlarm` = 1 row written), 5 GB stored per account, 1 GB per object (FAQ), 2 MB per row/value, 100 KB per SQL statement, 100 classes per account; limits reset 00:00 UTC, past one the operation fails. Fit: a link code ≈ 1 save row + 1 try-count row + at most 1 alarm set; a wrong guess = 1 row; the worker only sets an alarm when none is set or it's later. KV's free plan would allow only 1,000 writes/day — the reason for the SQLite object. Save codes are bound values (not in the SQL text), ≤ 300,000 characters, far under 2 MB; new codes stop at 900 MB stored (the 1 GB object).
- F96 judgement calls: (1) fetching a code does NOT delete it — a third device / a retry after full storage; "Delete my data" from either device ends it. (2) The cloud is its own small worker (`cloud/worker.ts` + `cloud/wrangler.json`, `<game>-saves`, port 1998), not inside a rooms game's party worker — a rooms deploy never touches saves; installed only with `--cloud`. (3) Uploads are limited too (`cloud.uploadsPerHour` 20) so one address can't fill the store. (4) Malformed typing ("hello") is refused without counting as a guess (it can't match anything). (5) Addresses only as a SHA-256 scramble, only for the hour. (6) No Cloudflare type package: the worker is a plain class with `fetch()` + `alarm()` and writes out the few shapes it uses (typechecks under Goops' `erasableSyntaxOnly`). (7) "Make a link code" with nothing saved yet says so instead of sending an empty code. (8) The Save code screen's body is now one ScrollArea (it's taller) — no UI kit change.
- F96 surprises: wrangler dev sets CF-Connecting-IP locally, so the guess limit really counts per address there too (curl and the browser shared 127.0.0.1's budget — the proof's 20-wrong run saw 9 + 11 because one earlier wrong try was the deleted code). The kit's style uppercases toasts (CSS) — Playwright's innerText reads them in capitals; compare textContent. The "didn't work" sentence says "7 days" from the game's config even on a TEST_KEEP_SECONDS server (expected: the test var is server-only).
