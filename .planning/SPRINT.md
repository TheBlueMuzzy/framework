## F89 🧱 Crash reports from players
Done when: a game with the crashes module catches its errors (script errors, unhandled promise failures, failed asset loads, React errors, lost WebGL) and sends each kind once per session (5 at most) with the version and the last game moments, holding them while offline; a small worker of its own on the game's Cloudflare groups them by kind (count, first/last seen, versions, a few samples) with hard limits (size at the door, per address with a never-stored salted hash, a daily cap, samples per kind per day) and nothing personal stored; built source maps never ship and a local command prints each error with real file names and lines; session start says "N new errors from players, M came back since last time" for a game whose STATE names its crash server; Settings has the switch + privacy line and a broken game shows "Something broke — reload"; check:framework checks the wiring and that no .map file ships.
