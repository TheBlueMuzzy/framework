- F91 — Translation readiness, task 1 (2026-10-27):
  - Research (web, 2026-10-27): Godot's built-in pseudolocalisation lengthens by 30% by default ("sufficient for most cases"), with accents and doubled vowels as other options (docs.godotengine.org, i18n/pseudolocalization); Netflix Games' i18n requirements run a pseudo-loc pass that lengthens strings, and note Thai grows up to 70% TALLER, so truncation or overlap in pseudo text = the same bug once translated (backlothelp.netflix.com). The usual "short labels grow most" table (IBM) wasn't found at its source today → not relied on; our pass uses ~40% (above Godot's 30%) with a minimum, since a 2-letter "OK" grows more than a sentence. eslint-plugin-i18next `no-literal-string` checks JSX text by default and props only when listed (`jsx-attributes.include`) — the same split as ours.
  - Measured (draft in dev/.scratch/framework-f91/measure-text.mjs, read-only; module copies, Dev Kit game tools, tests left out). All four games keep words in content/text/en.json.
    - JSX text + player props (title, label, aria-label, placeholder, alt, …): starter 0 · Roll Better 0 · Goops 1 (Spotlight aria-label "Tip") · Glyphtender 6 (4 label, 2 aria-label). The externalize-text skill already moved the screens' words.
    - Sentence-like strings anywhere (a capital, a space, letters; not imports, keys, console, Error): starter 6 · Roll Better 7 · Goops 4 · Glyphtender 38.
      - Real player words: Roll Better's 7 room errors in src/hooks/useRoom.ts ("Room not found", "Connection lost", "Room code must be 4 letters"…).
      - Not player words: the rules' check() refusal reasons (starter rules.ts ×4, Glyphtender engine ×~15) — the starter only uses them as allowed / refused (match.ts:91), never shown; Goops' shader error prefixes (thrown); Glyphtender's AI meter labels (the Dev Kit's arena report, src/ai/meters.ts) and "A draw" in a log call.
    - Decision: the rule = JSX text + the player props + sentence-like strings, skipping imports, object keys, console.*, Error messages, anything inside a `throw`, and what a rules `check` returns; the rest says `// text-ok: <why>` (a Dev Kit report label).
