## D. Surprises
- **Two tutorials, built twice.** Both games built a full tutorial system on their own — Goops as a "step player" fed by JSON files, Glyphtender as steps written in code. Same jobs, different shapes. That's the strongest brick case in either game, but merging means rewriting one of them.
- **Goops is the second game for two frozen modules.** Saves and crashes both fit Goops today; taking them would unfreeze both (two games use them). The saves module was even tested on a copy of Goops' progress already.
- **Goops has no crash catcher at all.** If something breaks on a player's phone, the screen goes blank and nobody is told.
- **The ladder was built to leave** — it has its own README and "can move into the framework" — but no second game has ranks, so the recipe says it stays.
- **Goops' check script has drifted from the template.** Its `check:fast` (in `package.json`) runs four commands one after another instead of `check-all.mjs fast`, and its fast list has no "framework (code)" check (its own comment says to add one). It's a template copy that has drifted, not a candidate.
- **A possible bug fix travels the other way.** Goops found that the "update on first visit" line sometimes leaves a page on the old version, and fixed it; Glyphtender has the plain line. Worth a check.
