# v0.44.0

## Highlights
Steadier and safer. The Dev Kit's save and library calls now only answer the game page the dev server served, so a hand-made request from another device on the Wi-Fi is refused. A release build can no longer overwrite the crash maps of a version players already run.

## Breaking
- Dev Kit 0.32.0: nothing to change when the installer updates both halves. Restart `npm run dev` after updating, and reload any page left open across the restart. Only a game whose own code calls a `/__devkit/` route has to add `...devkitKeyHeaders()` (from `src/devkit/saveContent`) to that call's headers.

## New
- Dev Kit 0.32.0: every Dev Kit call carries a key that is made fresh each time the dev server starts and placed in the page it serves. Every browser that opened the game still saves (desktop, laptop and phone); a request made by hand is refused with a plain message.
- Crash reports 0.3.1: a second release build of the same version stops, with a plain message and nothing moved, instead of replacing the crash maps already filed for that version.

## Fixed
- The turn-based starter's online test no longer fails at random on GitHub: it waits for each move to reach both players before the next one.
- The hand-off check now reads feature names from the project the work happened in, not from the folder the chat started in.
