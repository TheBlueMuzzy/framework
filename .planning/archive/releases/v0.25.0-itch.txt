v0.25.0 — 2026-10-26

The UI kit and saves now hold up in WebKit, the engine every iPhone browser uses, not only in Chrome. Symbols like ⚙ and ❤ keep their button's size however a phone draws them, a card too tall for a sideways phone keeps its last buttons in sight, and saves are proven in Chrome, Safari's engine and Firefox.

NEW
• The screenshot run can also run in WebKit (npm run shoot:webkit — 504 shots, about 10 minutes), and npm run compare:engines lists any words that wrap differently between Chrome and WebKit.
• UI kit 0.35.7: a card that has to scroll keeps its last row of buttons stuck at its bottom, with a soft fade above it so a line cut where it scrolls under the buttons reads as "scroll down". A card that fits looks exactly as before.
• Saves 0.6.4: proven in real Chrome, WebKit and Firefox — save, reload, load, upgrade, save code, a full disk and a private window.

CHANGED
• UI kit 0.35.5: a HUD's typed icon (❤, 🪙) sits in a fixed box the width of an emoji, so on Windows' Chrome the Health bar is about 7 px shorter than before.

FIXED
• UI kit 0.35.5: the ⚙ icon button no longer grows from 44 px to 55–61 px when a phone draws ⚙ as a colour emoji; a symbol too wide for its button is drawn smaller to fit.
• UI kit 0.35.5: on a sideways phone in Pixel, "I'M READY" no longer sits cut off on the room card's bottom edge in Safari's engine.
• UI kit 0.35.5: "HOW TO PLAY" (Neon, sideways) and "Debt to the company" no longer wrap to a second line in Safari's engine.
• UI kit 0.35.6: an icon button's symbol keeps its room on Linux, where text snaps to whole pixels.
• Saves 0.6.4: a private window that won't store anything is told as "this browser won't let the game save", not "storage is full"; an older Firefox's full disk is now told as full.

KNOWN ISSUES
• WebKit on a Windows PC is iPhone's engine, but not its fonts, scrolling or safe areas: a look on a real iPhone is still the final word.
• In Safari's engine the room card's "Share this code with your friends" takes 3 lines where Chrome takes 2 (Safari balances lines differently). Accepted: the card keeps its buttons in sight while it scrolls.
