## F06 🧱 The game-ui skill
Done when: when any game needs UI, the `game-ui` skill kicks in by itself, gets the kit (from `dev/framework`, or clones it), gets a style picked (5-style sheet), installs/updates the kit in the game, builds from the catalog, checks the rules and screenshots — with no hand-steering; BMUZ steps call it by name.

- [x] 🤖 3. Install/update tool `ui-kit/scripts/install-kit.mjs <game>` — copies `kit/` → `<game>/src/ui/kit/` with a VERSION stamp; creates `content/ui/style.json` + `content/ui/settings.json`; merges font credits into `content/credits.json`; on update shows what changes

On an update it lists changed / added / removed kit files first, and deletes removed ones (games never edit the kit — edits go to the framework).
