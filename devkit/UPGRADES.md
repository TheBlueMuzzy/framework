# Dev Kit — upgrade notes

Hand steps a game does when it updates this module, newest first. `install-module.mjs` prints the ones between the game's version and the new one.
Format: `- <version>: <step>` (LOOK CHANGE = sizes or looks change: re-take the game's screenshots and show Muzzy before re-recording them) · `Needs Dev Kit: <version>` = the install is refused on an older Dev Kit.

No required hand steps so far: the installer wires everything (Glyphtender 0.20.2 → 0.28.1: 0 hand fixes). Update it FIRST — it runs every other module's checks.

- 0.32.0: Nothing required — the installer replaces both halves (the page's key comes from `vite-plugins/devkit/devkitVite.ts`, the Dev Kit sends it from `src/devkit/`), and every browser that opens the game gets it. Restart `npm run dev` after updating, and reload a page left open across a restart (an old page's Save says "Refused: … no Dev Kit key"). Only if the game's OWN code (not the Dev Kit) fetches a `/__devkit/` route: add `...devkitKeyHeaders()` (from `src/devkit/saveContent`) to its headers. An e2e that intercepts `**/__devkit/save` with `page.route` needs nothing.
- 0.31.0: Nothing required. Optional: replace your own open-the-Dev-Kit code in `e2e/*.mjs` (a ` press + a fixed wait, a tab-paging helper like Glyphtender's `e2e/devkit-tabs.mjs`) with `import { openDevKit, openTab, closeDevKit } from '../src/devkit/e2e.mjs'` — `await openTab(page, 'Tuning')` opens the panel when needed, finds the tab on any page of the tab row and returns its panel (README *E2E helpers*).
- 0.30.0: Nothing required. The Lessons tab types a step's words itself (saved into `content/text/en.json`, only the changed lines), and the Text and Lessons tabs share their edits. Optional, for words that change on screen while you type (a tutorial bubble): read the words through `liveFile('text/en', en)` and redraw on `onTuning('text/en', …)` where they're drawn — README *Live words — optional*; the turn-based starter's `src/ui/LessonView.tsx` does it. A game that doesn't sees the words after Save, as before. If the game's e2e looks for a lesson's words page-wide (`page.getByText(words, { exact: true })`), look inside the bubble instead (`page.locator('.kit-callout').getByText(…)`): the Dev Kit's hidden Lessons tab now holds the same words in its boxes (the starter's tutorial e2e hit that).
- 0.29.0: Nothing required. A game with the Tutorial module gets the **Lessons tab** by itself, and its `content/lessons/*.json` imports become live. Optional, one line: `lessons: { runner }` (or `{ runner, start: (id, at) => … }`) in the adapter for the tab's ▶ buttons (README *The Lessons tab*). Goops: your own Lessons tab (id `lessons`) keeps its place over the kit's; when you swap to the kit's, delete it and add `lessons: { runner, start: (id, at) => session.startLesson?.(id, at + 1) ?? false }` (Goops counts steps from 1) — and its `liveTuning('lesson-<id>', …)` wrap can go (the import is live now).
